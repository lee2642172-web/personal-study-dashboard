# MY DASHBOARD — 개인 종합 학습 대시보드 V1

React · TypeScript · Vite · Tailwind CSS · React Router · Lucide 기반 개인 학습 관리 앱입니다. 기존 카드 디자인과 PC/iPad 반응형 레이아웃을 유지합니다.

## 실행 및 검사

Node.js 24 / npm 11 환경에서 검증했습니다.

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
npm run preview
```

클라우드에서 npm 기본 캐시 쓰기가 제한되면 `npm ci --cache /workspace/.npm-cache`를 사용합니다. Vercel 배포용 `vercel.json`은 SPA 상세 URL을 `index.html`로 연결합니다.

## 구현한 기능

- **HOME**: 오늘·이번 주(월~일)·이번 달의 실제 학습·할 일·과업 작업시간 합계, 날짜별 막대그래프, 회독별 관세사 강의 진도, EBS 카드와 영어 교재·단어장 통합 진도 패널을 표시합니다. 큰 안내 박스와 단순 이동 카드·개수 통계·긴 목표/자료 목록은 제거했습니다. 실제 학습일·할 일 완료일·과업 작업일 기준으로 시간을 합산합니다. 기존 자료 정비 기록도 실제 입력 시간이 있으면 함께 합산합니다. 할 일의 시간 미입력은 0분이며 과거 학습·작업의 미입력 시간은 추정하지 않습니다. 취소·삭제된 기록은 합산하지 않습니다.
- **캘린더**: 독립 메뉴 `/calendar`. 월 이동·오늘 강조·날짜별 일정 조회, 일정 추가·수정·삭제, 여러 날에 걸친 일정, 선택적 시작/종료 시간·메모·분야·시험 목표 연결을 지원합니다. 시험·시험 접수(시작/마감 구분)·성적 발표·학습·기타로 분류하고 선택한 날짜의 시험 D-Day를 표시합니다.
- **외국어**: 영어 MAIN, 중국어·일본어·스페인어별 자료 등록 및 이력 화면. 중국어·스페인어는 연속된 Day 번호 추가, 날짜·시간별 학습 및 회독·복습 기록을 지원합니다. Excel 정리 작업은 별도 장기 과업에서 관리합니다.
- **자격증**: 관세사 MAIN, 무역영어 1급·원산지관리사·보세사·컴활의 기본 자료 등록 화면. 관세사 과목의 **무역영어 이론·협약 60강**, **내국소비세법 38강**, **관세법개론 98강**, **원가관리회계 33강**, **재무회계 현재 114강**은 사용자 제공 목록으로 등록했습니다.
- **영어**: EBS 3개 강좌, Basic / Intermediate Grammar in Use, 일반 단어장·구동사 자료, 패턴·회화문·학원 교재·독서 자료의 메타데이터와 관리 화면.
- **보관함**: 자료 등록·설정 수정, 분야·상태 필터와 검색. 상태는 보관 중 / 학습 중 / 보류 / 완료. 전체량, 목표 회독 수, 요일, 시작일, 예상 시간 및 루틴 수정 가능. 기존 기록은 설정·상태 변경 후에도 보존됩니다.
- **학습 관리**: 발행 월별 EBS 회차, Unit / Day / 페이지별 완료·실제 날짜·시간, 회독별 진도 및 누적 반복 기록. 완료를 해제해도 기록과 시간은 보존됩니다. 목표 회독 이후도 추가 기록 가능하며 동일 항목 반복이 해당 회독의 완료량을 부풀리지 않습니다.
- **과업**: 제목으로 등록하는 일반 할 일과 기존 장기 과업을 별도 영역에서 관리합니다. 일반 할 일의 완료 날짜·시간 수정·취소·삭제를 지원하고, 장기 과업은 Day 구간 / 수량 / 회독 / 단계별 진행과 실제 작업 이력을 유지합니다. 영어·스페인어·중국어·일본어의 진행 중인 과업과 전체 과업 메뉴가 같은 데이터를 사용하며, `/tasks/:id`에서 설정·이력 수정·삭제를 지원합니다. 상태는 예정 / 진행 중 / 보류 / 완료이고 완료 상태는 직접 관리합니다.
- **학습 기록**: 전체 기간의 기존 이력을 기본 표시하며 실제 날짜 / 분야 / 활동 구분으로 필터링합니다. 취소한 기록은 목록·선택 건수·시간 합계에서 제외합니다. 학습·복습·할 일·과업 작업·자료 정비를 날짜별 단일 시간 합계로 확인하고 원본 기록을 수정할 수 있습니다.
- **목표 관리**: 독립 목표 등록·수정, 현재/목표 등급, 상태, 목표일·취득일·유효기간 종료일, 사내 인정 여부, 선택적 선행 목표·요구 등급. 순환 선행 조건은 막습니다.
- **OPIc**: 다른 교재 회독과 무관한 독립 과정, 주제별 영작·말하기 메모 및 시간 기록. 전용 교재는 아직 등록되어 있지 않습니다. OPI 목표 수정에서 OPIc + AL을 선택적 선행 조건으로 지정할 수 있습니다.
- **저장**: Supabase 연결·이메일 로그인 후 계정별 온라인 자동 저장과 PC·iPad 동기화. 연결 전에는 브라우저 저장을 유지합니다. 최초 연결과 충돌 시 기록 선택·교체 전 백업을 제공하며 저장 상태를 실제 서버 응답에 맞춰 표시합니다.

## 초기 데이터의 출처와 집계

`src/initialData.ts`에는 이번에 사용자가 제공한 정보만 등록되어 있습니다.

- EBS: 2026년 4월 1일~7일의 발행 요일 기준으로 Start / Easy 각 5회, Power 6회 완료 이력. **회차 발행일은 실제 청취일이 아닙니다.** 요일 기반 목록은 실제 휴방·편성을 보장하지 않으며 외부 편성표를 조회하지 않습니다.
- Basic: 1회독 Unit 1~6 완료. 전체 113 Units, 목표 10회독.
- 위 이력의 **실제 날짜와 시간은 모두 미입력**입니다. 기존 이력에 약 18분 등의 예상 시간을 소급해 넣지 않습니다. 이후 EBS 빠른 완료는 사용자가 지정한 기본값 18분을 기록하며 수정할 수 있습니다.
- 일반 단어장 303 Days / 약 3,030단어는 자료 규모입니다. 실제 복습 완료량은 기록 전입니다.
- OPIc IM2 → AL / TOEFL iBT 목표 점수 미정 / OPI AM 장기 목표는 독립 목표로 등록됩니다. 날짜·유효기간은 임의로 채우지 않습니다.
- 다른 언어와 자격증에는 가상 학습 자료·시간·진도를 새로 만들지 않았습니다.

기존 시제품의 파일과 데이터는 삭제하지 않았습니다. `src/data.ts`와 `src/LegacyApp.tsx`에 보존되며 `/prototype` 및 `/prototype/system`에서 열 수 있습니다. 이 화면은 가상 데이터가 포함된 **이전 시제품**으로 명시하며, V1의 실제 집계에 합산하지 않습니다. 기존 `/customs`, `/system`, `/activity`, 언어별 상세 주소는 V1 대응 화면으로 연결됩니다.

기존 저장 키 `personal-study-dashboard:v1`은 로그인 전 기록으로 보존합니다. 계정별 기기 캐시는 프로젝트·사용자별 별도 키로 분리하여 로그아웃·계정 변경 시 다른 계정으로 기록이 전송되지 않도록 했습니다. 학습 자료·기록·진도·목표·할 일·장기 과업·일정 전체를 같은 계정의 온라인 문서로 저장합니다. 설정 방법은 [온라인 저장 연결 안내](docs/online-storage.md)를 참고하세요.

**실제 Supabase 프로젝트 설정·로그인 전에는 기기에만 저장됩니다.** 연결 후에는 동일 프로젝트·이메일 계정의 기록을 공유합니다. 로컬 변경은 약 0.7초 후 저장하며 다른 기기의 변경은 화면 복귀·재연결·약 30초 주기로 확인합니다. 서버의 버전 번호로 동시 변경을 감지하고 자동 덮어쓰기를 중단합니다. 충돌 시 양쪽 기록을 내려받거나 사용할 기록을 선택할 수 있고, 교체 전 최근 4개 사본을 해당 계정의 기기 캐시에 보관합니다. 자동 항목별 병합과 온라인 버전 이력은 제공하지 않습니다. 브라우저 데이터를 삭제하면 아직 온라인에 저장되지 않은 변경과 기기 백업은 사라질 수 있습니다. JSON 내보내기는 제공하지만 앱 내 JSON 파일 복원은 아직 없습니다.

## 이번 범위에 포함하지 않은 기능

실제 Excel 파일 업로드/파싱/변환, EBS 콘텐츠 재생 및 실제 편성 조회, 음성 녹음/평가, 자동 학습시간 측정, 실제 시험 접수·점수 조회는 구현하지 않았습니다. 자료 등록은 메타데이터 등록이며 외부 파일 자체를 보관하지 않습니다. 독서 자료는 전체 페이지 수 입력 후 페이지별 진도를 기록하는 구조를 제공합니다. 온라인 저장 기능은 구현했지만 실제 프로젝트 생성·SQL 실행·연결값·로그인은 별도로 필요하며, 이 저장소만 배포했다고 온라인 저장이 활성화되지는 않습니다.

## EBS 통합 캘린더

- 영어 화면의 **EBS 오디오어학당 통합 카드**에서 세 강좌의 월간 진도를 함께 확인하고 `/english/ebs`로 이동합니다. HOME의 진행 중 자료에서도 통합 카드로 표시합니다.
- 월간 캘린더는 콘텐츠 **발행일** 기준입니다. 파랑(Start), 초록(Easy), 보라(Power) 표시로 강좌별 완료 이력을 구분합니다. 빈 원은 기록 없음, 채운 원은 저장된 완료 이력, 대시는 기본 발행 없음입니다. 날짜를 선택하면 해당 발행일의 강좌별 내역이 열립니다.
- Start/Easy 월~금, Power 월~토의 요일 기반 목록이며, 실제 휴방·편성은 별도 확인이 필요합니다. 발행 시작일·요일·예상 길이는 각 강좌의 자료 설정에서 수정할 수 있습니다. 기본 시작일은 2026-04-01입니다.
- 개별 완료 기록, 실제 청취일·시간 수정, 재청취 기록, 해당 발행일의 오늘 미기록 강좌를 함께 기록할 수 있습니다. 오늘 날짜로 이미 완료한 강좌의 기록은 변경하지 않습니다. 개별 완료와 일괄 완료는 입력창 없이 기기의 로컬 날짜와 기본 18분으로 새 기록을 만듭니다. 기존 날짜·시간 미입력 이력은 소급 변경하지 않습니다.
- 월간 완료율은 강좌별 고유 발행일 기준으로 계산합니다. 같은 회차 재청취는 이력·시간으로 보존하되 완료율을 중복 증가시키지 않습니다. 미래 발행 일정은 예정으로 표시하며 완료 처리와 완료율 분모에서 제외합니다. 완료 기록이 없으면 학습 여부를 추정하지 않습니다.
- 자료의 `groupId: "ebs-audio"`로만 그룹을 연결합니다. 기존 저장 데이터의 `ebs-0`, `ebs-1`, `ebs-2`는 자료 ID·기록 ID·실제 날짜·시간·완료 상태를 변경하지 않고 그룹 정보만 추가합니다. 저장 버전과 키는 유지됩니다. 발행 요일을 바꿔도 과거 일정 밖의 기록은 선택 날짜의 내역에 남습니다. 발행일 미입력 또는 그룹 시작일 이전 이력도 별도 접힌 영역에서 보존하며 날짜 확인 후 수정할 수 있습니다.
- 기존 `/materials/ebs-0`, `/materials/ebs-1`, `/materials/ebs-2` 주소는 통합 캘린더로 연결됩니다. 개별 자료 메타데이터는 보관함에 유지되며, 단어장·Grammar in Use·다른 오디오 자료에는 통합 UI를 적용하지 않습니다.

## EBS 한 번에 완료 기록

- 기본 흐름은 **회차 선택 → 완료**입니다. 버튼을 누르면 입력창 없이 콘텐츠 발행일과 버튼을 누른 기기의 로컬 날짜(실제 학습일), 기본 18분, 완료 상태를 저장합니다. 오늘 일괄 기록도 같은 기본값을 사용하며 오늘 이미 완료한 강좌는 건드리지 않습니다.
- 미완료 회차는 체크 아이콘 없는 파란색 **학습 완료하기** 행동 버튼입니다. 완료 시에만 체크·↩와 초록색 **학습 완료** 상태 버튼을 표시합니다. 버튼을 다시 누르면 즉시 완료 취소되며, 한 번 더 누르면 클릭한 날의 기본 18분 학습을 새로 기록합니다. 키보드·스크린리더에는 `aria-pressed`로 상태를 전달합니다.
- **추가 학습**은 별도의 18분 복습 기록을 추가하며, 월간 완료율은 중복 증가하지 않습니다. **기록 수정**에서 실제 날짜·시간을 바꿀 수 있고, 펼친 이력에서는 각 기록을 따로 수정할 수 있습니다.
- 새 EBS 기록은 `contentDate`(콘텐츠 발행일), `date`(실제 학습일)를 별도로 저장합니다. `item`은 기존 구조와의 호환을 위해 발행일을 함께 유지합니다. 이전 기록은 `item`을 발행일로 사용하며 기록을 삭제하거나 기본 시간을 소급 적용하지 않습니다.
- HOME은 **전체 / 오늘 / 이번 주 / 이번 달 / 특정 날짜**의 시간 통계를 지원합니다. 콘텐츠 발행일과 관계없이 실제 활동일을 기준으로 학습·복습·자료 정비·할 일·과업 작업시간을 함께 집계합니다. 날짜 또는 시간이 미입력인 이력은 보존하되 시간 합계에서는 제외합니다.
- 선택한 회차의 **오늘 청취 합계**와 강좌별 오늘 기록 여부를 표시합니다. 과거에 완료했어도 오늘 다시 들었다면 **오늘 미기록 N개 강좌 학습 기록**으로 강좌당 18분을 추가합니다. 이미 오늘 기록이 있는 강좌는 건드리지 않아 기본값 기준 3강좌는 54분으로 합산합니다. 과거의 실제 날짜·시간은 보존하며, 사용자 입력 없이 오늘 학습으로 추측하지 않습니다.
- `src/dates.ts`는 기기 로컬 날짜와 기간 계산, `src/studyTime.ts`는 실제 학습일 기반 시간 집계, `src/ebs.ts`는 중복 방지와 기본 18분 기록을 담당합니다. 기존 브라우저 캐시와 선택적 온라인 저장을 공통 저장 계층에서 처리합니다.

## 완료 토글과 시간 통계

- 완료를 취소하면 해당 회차의 완료·추가 학습 기록은 삭제하지 않고 `completed: false`, `voided: true`로 보관합니다. 취소 기록은 완료율과 HOME·학습 기록 화면의 시간 합계에서 제외됩니다.
- 취소 후 다시 완료하면 기기 로컬 날짜·기본 18분으로 새 기록을 생성합니다. 취소했던 기록의 날짜·시간을 되살리지 않아 과거 날짜 때문에 오늘 합계에서 빠지는 문제를 방지합니다. 취소된 원본은 보존하고 기존 날짜·시간 미입력 이력을 소급 변경하지 않습니다.
- 취소한 기록은 내부에 보존하며 기본 학습 기록·청취 이력 목록에서는 숨깁니다. 기록이 있었지만 모두 취소된 기간의 시간 합계는 0분으로 표시합니다.

## 영어 단어장 이어서 학습

일반 영어 단어장(303 Days)과 구동사·표현 단어장(35 Days)에 동일하게 적용됩니다. Grammar in Use·다른 자료의 기존 구조는 유지합니다.

- 최상단 **이어서 학습하기**에서 현재 회독의 다음 학습 Day로 이동합니다. 전체 Day 목록을 나열하지 않습니다.
- Day 번호 직접 입력은 유효한 범위 안에서 즉시 이동하며 이전/다음 Day 버튼도 제공합니다. 탐색한 Day는 실제 학습 진도와 별도로 저장됩니다. 과거 Day를 열어도 이어서 학습할 위치는 바뀌지 않습니다.
- 회독 선택·현재 Day·누적 복습 횟수·**복습 기록하기**·Day 이동을 하나의 패널에서 제공합니다. 전체 Day 목록은 기본 화면에 펼치지 않으며, 해당 Day의 상세 이력과 회독 현황·자료 설정은 접힌 보조 영역에서 확인합니다.
- **새 Day 학습**은 마지막 번호 다음 Day를 추가하면서 기기 로컬 날짜로 **신규 학습**을 함께 저장합니다. 실제 학습시간과 메모는 선택 입력이며, 입력한 시간은 HOME 통계에 포함합니다. 시간 미입력은 임의로 채우지 않습니다. 단어·예문 원문은 기존 Excel에서 관리합니다.
- 신규 학습은 `initialLearning: true`, `activity: "study"`로 저장합니다. Day별 **신규 학습 횟수**와 **복습 횟수**를 분리하며, 신규 학습 자체가 복습 회독을 완료시키지 않습니다. 기존 기록은 신규 학습으로 추측하거나 다시 분류하지 않습니다. Excel 서식 정리 등 자료 정비는 기존 과업·정비 시간과 구분합니다.
- 이미 완료한 회독은 Day 추가 시 그때의 Day 수를 `DayRoundState.totalDays`에 보존합니다. 진행 중인 회독과 새 회독은 늘어난 전체 Day 수를 사용합니다. 완료한 회독 범위 밖의 Day를 복습하려면 새 회독을 시작합니다.
- 신규 학습 기록 취소는 기록·시간만 삭제하며 추가한 Day와 다른 복습 기록은 보존합니다. 상세 이력의 **이 Day 신규 학습 기록**으로 기존 Day에도 다시 기록할 수 있습니다. 신규 학습의 날짜·시간·메모는 기록 수정에서 변경할 수 있습니다.
- **복습 기록하기**는 기기 로컬 날짜로 새 복습 이력을 저장합니다. 기록을 추가·수정·취소해도 선택한 Day는 이동하지 않습니다. 같은 Day를 여러 번 기록할 수 있으며 누적 횟수에 반영됩니다. 학습시간은 임의로 추정하지 않고 미입력으로 두며 기록 수정에서 입력할 수 있습니다. 실제 단어·예문은 기존 Excel 자료를 참고하세요.
- 회독별 `nextDay`(다음 미완료 Day), `lastOpenedDay`(선택한 Day), 최근 복습 ID를 `DashboardData.dayBooks`에 별도로 저장합니다. `activeRound`로 현재 회독을 유지하며 재접속하면 진행 중이던 회독의 마지막 선택 Day를 표시합니다. 다른 회독으로 전환해도 각 회독의 선택 위치는 유지됩니다.
- 기존 저장 데이터에 이 정보가 없으면 기록을 보존하면서 초기화합니다. **가장 높은 완료 Day + 1을 사용하지 않습니다.** 활성 완료 기록 사이의 첫 미완료 Day를 계산하므로 Day 1·3·100이 완료되었어도 다음 미완료 Day는 2입니다. 회독 현황에서 해당 Day를 직접 열 수 있습니다. 이전의 `01` 같은 Day 번호도 같은 Day로 읽습니다.
- **최근 기록 취소**와 상세 이력의 **기록 취소**는 해당 복습 기록을 실제로 삭제합니다. 회독 이력·누적 횟수·시간 집계와 다음 미완료 Day도 남아 있는 기록을 기준으로 갱신합니다. 기존에 취소 상태로 보관되던 단어장 기록도 불러올 때 정리합니다. EBS 취소는 내부 보관 후 집계에서 제외하며, 다시 완료할 때는 새 청취 기록을 생성합니다.
- 회독 선택·번호 직접 입력·새 회독 시작을 지원합니다. 목표 회독 횟수와 무관하게 추가할 수 있으며 마지막 Day를 기록해도 새 회독을 자동 생성하지 않습니다. 기존 회독의 진도와 선택 위치는 각각 보존됩니다.
- 기존 학습 기록 화면에서 날짜·시간·Day·회독을 수정하는 경우에도 같은 저장 로직으로 다음 미완료 Day를 갱신하고 선택 위치는 유지합니다. 자료 상태를 변경해도 학습 기록은 보존합니다. 자료 전체량 변경 시 위치를 유효 범위로 조정합니다.

주요 파일: `src/dayLearning.ts`(진도·탐색·회독 및 취소 로직), `src/DayBook.tsx`(단어장 UI), `tests/dayLearning.test.mjs`(위치 분리·순서가 뒤섞인 이력·취소·회독·저장 회귀 검사). 연결 전에는 같은 브라우저에서 복원하고, 온라인 저장을 연결하면 회독·위치·기록도 계정별로 동기화합니다.


## EBS 오디오어학당 다음 날 복습

- EBS 화면 최상단에서 실제 학습일의 다음 **달력 날짜**에 복습할 회차를 표시합니다. 발행일과 실제 학습일은 구분하며 실제 날짜가 없는 과거 이력, 취소·미완료·정비 기록은 일정으로 추측하지 않습니다.
- HOME의 오늘 학습 목록 아래에서도 EBS 복습할 회차 수와 내일 예정 회차 수를 확인할 수 있습니다. 다른 자료의 복습 자동 추천은 이번 변경에 포함하지 않습니다.
- 같은 강좌·발행 회차를 같은 날 여러 번 청취하면 복습 추천은 하나입니다. 실제 날짜가 있는 일반 청취·추가 학습은 다음 날 복습 대상이 되며, 이미 다음 날 이후에 재청취한 이력이 있으면 복습 완료로 표시합니다.
- 놓친 복습은 완료 전까지 남습니다. 토요일 학습의 일요일 복습도 가능하며 발행 요일에 제한받지 않습니다. 목록을 표시하는 것만으로 학습 기록이나 시간을 만들지 않습니다.
- **복습 완료하기**를 누르면 실제 복습일과 완료 상태를 별도의 `review` 이력으로 저장합니다. 복습시간은 자동으로 추정하지 않고 미입력(`null`)으로 두며, `reviewOf`로 원래 실제 학습 기록에 연결합니다. 자동으로 추천한 복습의 완료 기록은 또 다른 다음 날 복습을 생성하지 않습니다.
- 완료 후 **시간 입력**에서 실제 시간을 선택적으로 기록할 수 있습니다. 시간 미입력도 복습 완료로 유지되며 HOME 시간 합계에서는 제외합니다. 날짜·시간을 수정하거나 복습만 취소할 수 있습니다. 취소한 복습은 화면의 완료 내역·HOME 시간에서 제외되며 원래 청취 기록은 유지됩니다. 수정은 기존 기록 화면에서도 가능합니다.
- 브라우저 캐시와 연결한 온라인 저장소에 유지되며 브라우저 밖 알림은 제공하지 않습니다. 화면이 열린 상태에서도 로컬 날짜 변경 및 포커스 복귀 시 일정을 갱신합니다.
- 이전 버전에서 이미 저장된 복습 18분은 자동값인지 사용자가 입력한 값인지 구분할 정보가 없어 그대로 보존합니다. 필요하면 해당 복습의 기록 수정에서 시간을 비울 수 있습니다. 수업을 처음 청취하는 기본 18분은 유지됩니다.


## HOME 상황판 및 캘린더

- 일정·EBS 월간 캘린더는 **월~일** 순서이며 토요일은 하늘색, 일요일은 옅은 빨간색으로 요일·날짜를 구분합니다. 오늘·선택 날짜의 강조와 기존 일정·학습 기록은 유지합니다.
- 시간 요약의 **이번 주**는 월요일부터 일요일까지이며 실제로 기록한 오늘까지의 시간을 합산합니다. 그래프는 이번 주(월~일) / 최근 30일 / 월별(선택한 월의 일별 기록), 전체 / 분야별 필터를 지원하며 마우스·터치·키보드로 날짜와 분을 확인할 수 있습니다. 기록이 없는 날과 아직 오지 않은 날은 0입니다.
- 합계는 공통 활동 조회로 학습 로그·할 일 완료·과업 작업을 집계하며, 원본 종류와 ID로 중복을 방지합니다. 서로 다른 실제 재청취/복습/작업 세션은 각각 집계합니다. 실제 날짜 없는 기존 이력, 시간 미입력 기록, 취소·삭제 기록, 미래 실제 활동일은 요약과 그래프 합계에서 제외합니다. 기록 수정·취소 후 React 상태에서 즉시 재계산합니다.
- 관세사는 실제 등록된 강의 목록을 분모로, 선택한 회독의 완료 강의를 강의 번호별 한 번만 세어 **전체 완료 수 / 전체 등록 수**로 계산합니다. 과목 비율의 단순 평균을 사용하지 않습니다. 기본 1회독이며 기록이 있는 추가 회독을 선택할 수 있고, 과목 링크는 상세 페이지에도 같은 회독을 전달합니다. 재무회계는 추가 예정 표기를 유지합니다.
- EBS 통합 카드는 기존 표시·링크를 유지합니다. 나머지 영어 교재·단어장은 한 패널에 자료별 회독·완료 수·진행률·학습 위치를 표시하고 상세 화면으로 연결합니다. Grammar는 실제 기록의 현재 회독, 단어장은 저장된 선택 회독과 학습 위치를 사용합니다. 완료된 회독의 분량은 신규 Day 추가 후에도 유지하며, 신규 Day 학습·정비·취소 기록을 복습 완료량으로 세지 않습니다. Unit과 Day를 섞은 영어 전체 진도율은 만들지 않으며, 전체 분량이 없는 보관 자료는 접을 수 있는 목록으로 표시합니다. HOME 하단의 **학습 위치와 연습 기록 / 다가오는 일정 / 프로젝트 현황 / 최근 학습 기록** 네 영역은 현재 표시하지 않습니다. 각 상세 메뉴와 기존 자료·일정·과업·학습 기록은 유지합니다.
- `DashboardData.events?`를 같은 V1 저장소에 선택적으로 추가했습니다. 예전 저장 데이터에 일정이 없어도 그대로 읽으며 기존 학습 자료·목표·강의·기록은 바꾸지 않습니다. 일정 CRUD는 학습 기록/시간을 생성하지 않습니다. JSON 백업에도 일정이 포함됩니다.
- 다가오는 일정 컴포넌트는 보존하되 현재 HOME에는 표시하지 않습니다. 캘린더에서 시험·접수 시작·접수 마감·성적 발표를 별도로 등록할 수 있으며, 등록되지 않은 목표일이나 외부 시험 날짜를 추정해 일정을 만들지 않습니다.
- 일정도 기존 캐시와 계정별 온라인 저장에 포함됩니다. 외부 캘린더 연동·자동 시험 일정 수집·브라우저 밖 알림은 구현하지 않았습니다.
- `tests/dashboard.test.mjs`는 날짜/분야/중복/회독별 시간·진도를, `tests/calendar.test.mjs`는 일정 검증·CRUD·기간·D-Day·기존 저장소 호환·기록 보존을 검증합니다. 격리된 브라우저에서 HOME–상세 페이지 연동, 그래프 전환·터치, 일정 저장/수정/삭제/새로고침, PC·iPad·모바일 레이아웃을 추가 확인했습니다.


## 언어별 장기 과업

- 각 언어 페이지의 **진행 중인 과업**은 기본 3개까지만 간결하게 표시합니다. 나머지 보기, 보류·완료 필터, 언어별 전체 과업 링크를 제공합니다. `/tasks`에서는 분야·상태·관리 방식·제목/메모로 필터링하고 동일한 과업 상세 화면으로 연결합니다. HOME에 제거했던 과업 영역은 다시 추가하지 않습니다.
- 기존 `Task`에 선택적 `tracking`, `records`, `targetDate`를 확장했습니다. 예전 과업은 단계/체크 항목으로 그대로 읽으며 체크 상태·메모·ID를 보존합니다. **과업 설정**에서 관리 방식을 바꿀 수 있으며 기존 작업 이력과 참고 체크 항목은 삭제하지 않습니다. 현재 방식의 이력만 해당 진도에 합산합니다.
- **Day 구간형**: 전체 시작/종료 Day를 정하고 매번 실제 수행한 시작/종료 Day·날짜·메모를 자유롭게 입력합니다. 사전 구간을 고정하지 않습니다. 겹치거나 순서가 다른 구간은 합집합으로 계산하며 수정·삭제 시 다시 계산합니다. 기존 이력을 제외하도록 전체 범위를 줄이는 설정은 거부합니다. 중국어 등에서 501~550처럼 연속된 기존 번호를 그대로 사용할 수 있습니다.
- **수량형**: 단위와 전체 대상 수량을 설정하고 실제 처리 수량을 기록합니다. 대상 수량이 미정이면 누적 수량만 표시하고 진행률을 추정하지 않습니다. 목표보다 많은 기록은 실제 수량을 보존하고 초과 분량을 표시합니다.
- **회독형**: 대상·선택적 목표를 설정하고 회독마다 실제 날짜·메모를 저장합니다. 현재 완료 횟수는 실제 기록 건수입니다. 목표 후에도 무제한 기록할 수 있고, 기록 삭제 시 횟수도 줄어듭니다. 같은 날짜의 여러 회독은 각각 실제 기록으로 남습니다. 목표를 달성해도 과업을 최종 완료 상태로 바꾸지 않습니다.
- **단계형**: 단계를 자유롭게 추가·수정·삭제하고 단계별 메모와 완료 날짜를 보관합니다. 완료 체크 해제 시 그 단계의 완료 날짜도 해제하며, 다른 관리 방식에 단계 입력을 강제하지 않습니다. 과거 체크 기록에 날짜가 없으면 추측해 채우지 않습니다.
- 이력은 최근 실제 날짜부터 표시하고 20개씩 더 볼 수 있습니다. 날짜 범위·구간/메모 검색, 수정·실제 삭제를 지원합니다. 기록 입력 폼의 ID를 고정해 중복 제출이 같은 이력을 두 번 누적하지 않게 합니다.
- 새 과업 등록 양식에는 영어 Day 1~303 정비, 스페인어 미정리 단어 약 5,113개, 중국어 Day 311~500 추가 정리(190 Days), 일본어 히라가나·가타카나 각각의 회독 양식이 있습니다. 사용자가 양식을 선택하고 저장해야 과업이 생성됩니다. 양식만으로 작업 이력이나 학습 완료를 생성하지 않습니다. 모든 범위·수량·목표는 수정할 수 있습니다.
- 스페인어는 기존 Day 1~450을 보존하고 다음 신규 Day 451부터 직접 번호를 늘려 등록합니다. 단어 내용·시트·HSK 급수 구분은 대시보드에서 입력하거나 관리하지 않습니다.
- 작업 이력의 날짜·범위·완료 여부·시간은 `Task.records`에 한 번 저장하고, HOME과 학습 기록은 공통 활동 조회로 합산합니다. `data.logs`에 복제하지 않고 자료 진도·단어장 탐색/회독 위치를 바꾸지 않습니다. 과업 상태와 체크리스트는 자동으로 변경하지 않습니다.
- 기존 브라우저 캐시와 JSON 백업을 유지하며 연결 후에는 장기 과업도 계정별로 동기화합니다. Excel 파일 자체의 편집은 구현하지 않습니다. `tests/taskWork.test.mjs`에서 네 방식·이력 CRUD·구간 중복·기존 데이터 호환·통계 분리·무제한 회독을 검증합니다.


## 중국어·스페인어 Day 학습 및 번호 관리

- 언어 페이지의 **Day 학습**과 **Day 추가** 카드를 통해 학습과 자료 범위 관리를 분리합니다. 표제어·뜻·예문 입력, Excel/TSV 업로드, 중복 검토, 시트·급수 선택, 단어 수에 따른 Day 편입 조건은 화면에서 제거했습니다.
- **Day 추가·관리**(`/vocabulary/vocabulary-chinese`, `/vocabulary/vocabulary-spanish`)에서 마지막 Day 번호를 늘리거나 다음 Day를 하나 추가합니다. 중간 번호는 연속된 Day로 관리하며 개별 단어 입력이 필요하지 않습니다. Day 추가만으로 학습 완료·시간·과업 실적을 만들지 않습니다.
- 스페인어의 기본 등록 범위는 Day 1~450이며 다음 신규 번호는 451입니다. 중국어는 연결된 기존 자료·저장된 Day 범위·실제 기록·이전 편입 Day에서 마지막 번호를 확인합니다. 기존에 310보다 큰 Day가 있으면 그대로 사용하며 향후 정리 목표인 Day 500을 등록된 학습 범위로 사용하지 않습니다.
- `vocabularyDays.ts`는 번호 추가·범위 확장과 기존 자료 연결을 담당합니다. 다른 원본 자료의 단어 수나 선택하지 않은 Day 자료를 전체 Day 수로 환산하지 않습니다. 마지막 번호는 줄일 수 없으며, 중복·이전 화면에서 제출한 요청은 범위를 추가로 늘리지 않습니다.
- 범위 확장 전 기존 회독 상태를 저장해 완료된 회독의 범위·완료 상태와 진행 중인 회독의 선택 Day·다음 미완료 Day를 보존합니다. 새 회독은 확장된 전체 범위를 사용합니다. 자료 설정에서 전체량을 늘릴 때도 같은 로직을 사용합니다.
- Day 학습 패널에서 실제 학습 날짜·선택적 시간·회독별 복습을 기록합니다. 날짜·시간 수정과 취소는 기존 기록 기능을 사용하며 HOME 통계는 실제 학습일 기준으로 갱신합니다. 미입력 시간은 추정하지 않습니다.
- Excel 정리와 자료 구축은 `/tasks`의 별도 장기 과업에서 기록합니다. Day 추가·학습·취소는 과업 기록을 자동으로 바꾸지 않고, 과업 실적도 학습 기록이나 시간을 자동 생성하지 않습니다.
- 이전에 입력한 단어·시트·배치 데이터는 기존 V1 저장소와 JSON 백업에 그대로 보존하고 화면에서는 사용하지 않습니다. 호환성 검증·이전 편입 데이터 처리는 유지합니다. 학습 자료가 연결되지 않은 예전 데이터는 기존 Day 자료를 재사용하거나 선택해 연결하며 원본 학습 기록을 임의로 합치지 않습니다.
- 새로고침 후에도 범위·학습 기록·회독 위치를 기기 캐시에서 복원하며 온라인 저장 연결 후에는 같은 계정으로 공유합니다. `tests/vocabularyDays.test.mjs`에서 번호만으로 추가, 범위 확장·완료 회독 보존, 실제 날짜·시간·수정·취소, 기존 데이터 보존과 저장 복원을 검증합니다.


## 일반 할 일과 HOME 시간 통계

- HOME의 **간단한 할 일** 패널은 미완료 일반 할 일을 최대 3개 표시합니다. 오늘까지 마감인 항목, 마감일 없는 항목, 이후 마감 항목 순으로 보여주고 전체 목록은 과업 메뉴로 연결합니다. 체크 한 번으로 완료하며 옆의 분 입력은 선택입니다. 완료 직후 패널에서 취소할 수 있고 HOME의 오늘 기록·합계·차트와 과업 메뉴가 같은 저장 데이터를 사용합니다.
- `/tasks` 상단의 **일반 할 일**에서 제목만으로 등록합니다. 마감일·메모는 선택이며, 소요시간(0 이상의 정수 분)을 입력하거나 비운 채 **완료**를 누르면 기기 로컬 날짜로 완료합니다. 시간 미입력은 0분으로 저장합니다.
- 할 일 / 완료 내역 / 전체 필터, 제목·메모 검색, 내역 수정·삭제와 완료 취소를 제공합니다. 완료된 항목의 날짜·시간도 수정할 수 있고 완료 취소 시 해당 완료 기록과 시간이 없어집니다. 이후 다시 완료하면 그 시점의 날짜와 새 시간을 한 번 기록합니다.
- `DashboardData.todos?`에 완료 날짜·시간을 한 번만 저장합니다. HOME 요약·일별 차트에서는 `dashboardTimeEntries`로 기존 학습 기록과 합산하며 별도의 학습 로그를 만들지 않습니다. 반복 클릭·새로고침·날짜/시간 수정으로 같은 시간이 중복 합산되지 않습니다. 학습 로그와 할 일의 ID가 같아도 집계 식별자를 구분합니다.
- 오늘 / 이번 주(월~일) / 이번 달과 이번 주 / 최근 30일 / 월별 일별 차트는 실제 완료일을 사용합니다. HOME **오늘의 기록** 목록에도 완료된 할 일을 같은 목록에 표시하고 클릭하면 완료 내역으로 이동합니다. 합계는 학습/기타 활동별로 나누지 않습니다. 기존 분야 필터를 선택하면 그 분야에 속한 학습 기록을 조회하며 분야 없는 일반 할 일은 전체 분야 합계에 포함됩니다.
- 하단 **장기 과업**과 언어별 장기 과업은 기존 `tasks`를 그대로 사용합니다. Excel 단어장 정리·수정의 Day/수량/회독/단계 기록을 일반 할 일로 자동 변환하지 않으며, 일반 할 일 등록·완료·취소는 기존 학습·과업·자료·회독 데이터를 바꾸지 않습니다.
- 저장 버전·키는 그대로 유지하고 `todos`가 없는 이전 데이터도 읽습니다. 기록은 기존 브라우저 캐시와 JSON 백업에 포함되며 온라인 저장 연결 후에는 같은 계정으로 공유합니다. `tests/todos.test.mjs`는 제목 등록, 선택 정보, 완료·수정·취소·삭제, 0분 처리, 중복 방지, 기간별 합계·차트, 저장 복원과 기존 데이터 보존을 검증합니다.


## 장기 과업의 날짜별 작업시간

- 모든 장기 과업 상세 화면의 **작업 기록 추가**에서 오늘을 기본으로 실제 날짜, 선택적 Day 구간/수량/회독/자유 범위, 소요시간, 작업 내용·메모를 기록합니다. 범위를 입력하지 않고 시간만 남길 수 있습니다. 체크리스트 과업도 Day 작업 구간을 기록할 수 있으며 기존 체크리스트 관리 방식은 바뀌지 않습니다.
- 새 기록은 **작업 중**이 기본입니다. 명시적으로 완료 체크한 구간·수량·회독만 해당 관리 방식의 진도에 반영합니다. 완료하지 않은 작업의 시간도 그대로 합산합니다. Day 구간은 자유롭게 입력하며 완료 구간의 합집합으로 중복 Day를 제외합니다. 같은 구간에 여러 날 작업한 시간은 각각 합산합니다.
- 기존 `TaskWorkRecord`에 선택적 `minutes`, `completed`, `scope`를 추가하고 범위 없는 `session` 기록을 지원합니다. 완료 표시가 없던 기존 구간·수량·회독 기록은 종전의 완료 진도를 유지합니다. 과거 시간은 임의로 추가하지 않습니다. 체크리스트와 기존 이력의 ID·상태·날짜·메모는 보존합니다.
- 상세 화면은 전체 진도·과업 상태·누적 작업시간·최근 작업 날짜·정비 완료 Day·작업 이력·세부사항 체크리스트 순으로 표시합니다. 예를 들어 200분은 **3시간 20분**으로 표시합니다. 이력은 날짜·범위·메모·시간으로 검색하고 수정·삭제할 수 있습니다.
- `activities.ts`는 실제 학습 로그, 할 일 완료, 과업 작업을 원본에서 조회합니다. 원본 레코드를 다른 저장소에 복제하지 않고 학습/할 일/과업+기록 ID를 구분하여 합산합니다. 작업 범위의 완료 여부나 과업의 진행/보류/완료 상태에 관계없이 입력된 소요시간을 실제 작업일에 반영합니다. 과업 완료를 취소해도 이미 기록한 시간은 유지됩니다.
- HOME의 오늘·이번 주(월~일)·이번 달·일별 차트와 오늘 기록 목록에 반영합니다. **학습 기록**에서도 같은 원본을 날짜별로 합산하고 과업·할 일 기록은 해당 원본 편집기로 수정합니다. 기존 자료 정비 로그도 같은 총합에 포함하며 순수 학습과 기타 활동의 시간 카드를 나누지 않습니다.
- 기존 V1 저장소와 JSON 백업을 그대로 사용합니다. `tests/taskTime.test.mjs`에서 200분 누적·중첩 구간·미완료 작업·수량/회독/시간만 기록·상태 변경·시간 수정/삭제·합계/차트·중복 방지·새로고침 복원·기존 학습 및 체크리스트 보존을 검증합니다.
