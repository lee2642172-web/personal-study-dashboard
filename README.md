# MY DASHBOARD — 개인 종합 학습 대시보드 V1

React · TypeScript · Vite · Tailwind CSS · React Router · Lucide 기반 개인 학습 관리 앱입니다. 기존 카드 디자인과 PC/iPad 반응형 레이아웃을 유지합니다.

## 실행 및 검사

Node.js 24 / npm 11 환경에서 검증했습니다.

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
npm run preview
```

클라우드에서 npm 기본 캐시 쓰기가 제한되면 `npm ci --cache /workspace/.npm-cache`를 사용합니다. Vercel 배포용 `vercel.json`은 SPA 상세 URL을 `index.html`로 연결합니다.

## 구현한 기능

- **HOME**: 최상단에 기기 로컬 날짜 기준 오늘의 학습·복습 목록과 총 시간을 표시합니다. 신규 Day 학습·재복습·OPIc 연습도 포함하며, 시간 미입력 기록은 목록에 남기고 합계에서는 제외합니다. 취소한 기록과 자료 정비는 학습 목록·합계에서 제외합니다. 기존 기간별 실제 입력 학습·복습시간 / 자료 정비시간 분리, 이력 수, 외국어·자격증 현황, 독립 목표, 진행 중 자료, 프로젝트 및 날짜가 있는 최근 활동. 추천 할 일을 자동 생성하지 않습니다.
- **외국어**: 영어 MAIN, 중국어·일본어·스페인어별 자료 등록 및 이력 화면.
- **자격증**: 관세사 MAIN, 무역영어 1급·원산지관리사·보세사·컴활의 기본 자료 등록 화면. 관세사 과목의 **무역영어 이론·협약 60강**은 사용자 제공 목록으로 등록했습니다.
- **영어**: EBS 3개 강좌, Basic / Intermediate Grammar in Use, 일반 단어장·구동사 자료, 패턴·회화문·학원 교재·독서 자료의 메타데이터와 관리 화면.
- **보관함**: 자료 등록·설정 수정, 분야·상태 필터와 검색. 상태는 보관 중 / 학습 중 / 보류 / 완료. 전체량, 목표 회독 수, 요일, 시작일, 예상 시간 및 루틴 수정 가능. 기존 기록은 설정·상태 변경 후에도 보존됩니다.
- **학습 관리**: 발행 월별 EBS 회차, Unit / Day / 페이지별 완료·실제 날짜·시간, 회독별 진도 및 누적 반복 기록. 완료를 해제해도 기록과 시간은 보존됩니다. 목표 회독 이후도 추가 기록 가능하며 동일 항목 반복이 해당 회독의 완료량을 부풀리지 않습니다.
- **과업**: 자유 과업·프로젝트 등록 및 수정, 체크 항목 관리. 일반 단어장 정비(다의어 분리 / Day별 예문량 조정 / 엑셀 양식 정리)는 복습과 별도 프로젝트로 등록되어 있습니다.
- **학습 기록**: 전체 기간의 기존 이력을 기본 표시하며 실제 날짜 / 분야 / 활동 구분으로 필터링합니다. 취소한 기록은 목록·선택 건수·시간 합계에서 제외합니다. 시간 합계와 기록 수정을 지원하며 자료 정비는 학습·복습과 분리합니다.
- **목표 관리**: 독립 목표 등록·수정, 현재/목표 등급, 상태, 목표일·취득일·유효기간 종료일, 사내 인정 여부, 선택적 선행 목표·요구 등급. 순환 선행 조건은 막습니다.
- **OPIc**: 다른 교재 회독과 무관한 독립 과정, 주제별 영작·말하기 메모 및 시간 기록. 전용 교재는 아직 등록되어 있지 않습니다. OPI 목표 수정에서 OPIc + AL을 선택적 선행 조건으로 지정할 수 있습니다.
- **로컬 저장**: 새로고침 후 복원, JSON 백업 다운로드. 읽을 수 없는 기존 저장 데이터는 덮어쓰지 않으며 저장 실패는 화면에 알립니다.

## 초기 데이터의 출처와 집계

`src/initialData.ts`에는 이번에 사용자가 제공한 정보만 등록되어 있습니다.

- EBS: 2026년 4월 1일~7일의 발행 요일 기준으로 Start / Easy 각 5회, Power 6회 완료 이력. **회차 발행일은 실제 청취일이 아닙니다.** 요일 기반 목록은 실제 휴방·편성을 보장하지 않으며 외부 편성표를 조회하지 않습니다.
- Basic: 1회독 Unit 1~6 완료. 전체 113 Units, 목표 10회독.
- 위 이력의 **실제 날짜와 시간은 모두 미입력**입니다. 기존 이력에 약 18분 등의 예상 시간을 소급해 넣지 않습니다. 이후 EBS 빠른 완료는 사용자가 지정한 기본값 18분을 기록하며 수정할 수 있습니다.
- 일반 단어장 303 Days / 약 3,030단어는 자료 규모입니다. 실제 복습 완료량은 기록 전입니다.
- OPIc IM2 → AL / TOEFL iBT 목표 점수 미정 / OPI AM 장기 목표는 독립 목표로 등록됩니다. 날짜·유효기간은 임의로 채우지 않습니다.
- 다른 언어와 자격증에는 가상 학습 자료·시간·진도를 새로 만들지 않았습니다.

기존 시제품의 파일과 데이터는 삭제하지 않았습니다. `src/data.ts`와 `src/LegacyApp.tsx`에 보존되며 `/prototype` 및 `/prototype/system`에서 열 수 있습니다. 이 화면은 가상 데이터가 포함된 **이전 시제품**으로 명시하며, V1의 실제 집계에 합산하지 않습니다. 기존 `/customs`, `/system`, `/activity`, 언어별 상세 주소는 V1 대응 화면으로 연결됩니다.

## 저장 및 확장 구조

```text
src/
  main.tsx       앱 셸, 내비게이션 및 V1 라우팅
  pages.tsx      HOME / 영어 / 자료 / 과업 / 기록 / 목표 화면
  forms.tsx      자료·학습 기록·목표·과업 입력 및 검증
  ui.tsx         공통 카드, 진행률, 접근성 모달
  model.ts       도메인 타입, 분야, 회차·진도·회독 계산
  initialData.ts 사용자 제공 정보와 날짜·시간 미입력 완료 이력
  storage.ts     DashboardRepository 인터페이스, localStorage 어댑터, 검증, JSON 내보내기
  state.tsx      React 상태 및 저장 오류 처리
  styles.css     기존 디자인 + V1 반응형 스타일
  LegacyApp.tsx  보존된 이전 시제품 화면
  data.ts        보존된 기존 시제품 데이터
  vite-env.d.ts  Vite 타입
 tests/model.test.mjs  초기 이력, 진도, 추가 회독 및 저장 회귀 검사
```

현재 저장 키는 `personal-study-dashboard:v1`입니다. 자료·기록·목표·과업은 `DashboardData`로 묶고 저장 호출을 `DashboardRepository` 뒤로 분리했습니다. 미래에 서버 저장소로 교체할 수 있으나 인증·충돌 해결·온라인 동기화는 구현하지 않았습니다.

**현재 저장 범위는 동일 브라우저·동일 사이트 주소입니다.** PC와 iPad, 개발 주소와 Vercel 주소, 다른 브라우저 사이에 자동 공유되지 않습니다. 브라우저 데이터 삭제 시 로컬 기록도 사라질 수 있으므로 JSON 백업을 보관하세요. 현재 JSON 내보내기는 제공하지만 앱 내 백업 복원 기능은 아직 없습니다.

## 이번 범위에 포함하지 않은 기능

온라인 DB·계정·기기 간 동기화, 실제 Excel 파일 업로드/파싱/변환, EBS 콘텐츠 재생 및 실제 편성 조회, 음성 녹음/평가, 자동 학습시간 측정, 실제 시험 접수·점수 조회는 구현하지 않았습니다. 자료 등록은 메타데이터 등록이며 외부 파일 자체를 보관하지 않습니다. 독서 자료는 전체 페이지 수 입력 후 페이지별 진도를 기록하는 구조를 제공합니다.

## EBS 통합 캘린더

- 영어 화면의 **EBS 오디오어학당 통합 카드**에서 세 강좌의 월간 진도를 함께 확인하고 `/english/ebs`로 이동합니다. HOME의 진행 중 자료에서도 통합 카드로 표시합니다.
- 월간 캘린더는 콘텐츠 **발행일** 기준입니다. 파랑(Start), 초록(Easy), 보라(Power) 표시로 강좌별 완료 이력을 구분합니다. 빈 원은 기록 없음, 채운 원은 저장된 완료 이력, 대시는 기본 발행 없음입니다. 날짜를 선택하면 해당 발행일의 강좌별 내역이 열립니다.
- Start/Easy 월~금, Power 월~토의 요일 기반 목록이며, 실제 휴방·편성은 별도 확인이 필요합니다. 발행 시작일·요일·예상 길이는 각 강좌의 자료 설정에서 수정할 수 있습니다. 기본 시작일은 2026-04-01입니다.
- 개별 완료 기록, 실제 청취일·시간 수정, 재청취 기록, 해당 발행일의 오늘 미기록 강좌를 함께 기록할 수 있습니다. 오늘 날짜로 이미 완료한 강좌의 기록은 변경하지 않습니다. 개별 완료와 일괄 완료는 입력창 없이 기기의 로컬 날짜와 기본 18분으로 새 기록을 만듭니다. 기존 날짜·시간 미입력 이력은 소급 변경하지 않습니다.
- 월간 완료율은 강좌별 고유 발행일 기준으로 계산합니다. 같은 회차 재청취는 이력·시간으로 보존하되 완료율을 중복 증가시키지 않습니다. 미래 발행 일정은 예정으로 표시하며 완료 처리와 완료율 분모에서 제외합니다. 완료 기록이 없으면 학습 여부를 추정하지 않습니다.
- 자료의 `groupId: "ebs-audio"`로만 그룹을 연결합니다. 기존 저장 데이터의 `ebs-0`, `ebs-1`, `ebs-2`는 자료 ID·기록 ID·실제 날짜·시간·완료 상태를 변경하지 않고 그룹 정보만 추가합니다. 저장 버전과 키는 유지됩니다. 발행 요일을 바꿔도 과거 일정 밖의 기록은 선택 날짜의 내역에 남습니다. 발행일 미입력 또는 그룹 시작일 이전 이력도 별도 접힌 영역에서 보존하며 날짜 확인 후 수정할 수 있습니다.
- 기존 `/materials/ebs-0`, `/materials/ebs-1`, `/materials/ebs-2` 주소는 통합 캘린더로 연결됩니다. 개별 자료 메타데이터는 보관함에 유지되며, 단어장·Grammar in Use·다른 오디오 자료에는 통합 UI를 적용하지 않습니다.
- `src/ebs.ts`: 그룹 호환 처리, 날짜·발행 일정, 고유 완료율 계산. `src/Ebs.tsx`: 통합 카드, 월간 캘린더, 날짜별 기록과 일괄 완료 UI. `tests/ebs.test.mjs`: 기존 데이터 호환·완료율 중복 방지·미래 회차·주말·월 이동·저장 회귀 검사.

## EBS 한 번에 완료 기록

- 기본 흐름은 **회차 선택 → 완료**입니다. 버튼을 누르면 입력창 없이 콘텐츠 발행일과 버튼을 누른 기기의 로컬 날짜(실제 학습일), 기본 18분, 완료 상태를 저장합니다. 오늘 일괄 기록도 같은 기본값을 사용하며 오늘 이미 완료한 강좌는 건드리지 않습니다.
- 미완료 회차는 체크 아이콘 없는 파란색 **학습 완료하기** 행동 버튼입니다. 완료 시에만 체크·↩와 초록색 **학습 완료** 상태 버튼을 표시합니다. 버튼을 다시 누르면 즉시 완료 취소되며, 한 번 더 누르면 클릭한 날의 기본 18분 학습을 새로 기록합니다. 키보드·스크린리더에는 `aria-pressed`로 상태를 전달합니다.
- **추가 학습**은 별도의 18분 복습 기록을 추가하며, 월간 완료율은 중복 증가하지 않습니다. **기록 수정**에서 실제 날짜·시간을 바꿀 수 있고, 펼친 이력에서는 각 기록을 따로 수정할 수 있습니다.
- 새 EBS 기록은 `contentDate`(콘텐츠 발행일), `date`(실제 학습일)를 별도로 저장합니다. `item`은 기존 구조와의 호환을 위해 발행일을 함께 유지합니다. 이전 기록은 `item`을 발행일로 사용하며 기록을 삭제하거나 기본 시간을 소급 적용하지 않습니다.
- HOME은 **전체 / 오늘 / 이번 주 / 이번 달 / 특정 날짜**의 시간 통계를 지원합니다. 콘텐츠 발행일과 관계없이 `date`를 기준으로 학습·복습시간을 집계하고 자료 정비시간은 분리합니다. 날짜 또는 시간이 미입력인 이력은 보존하되 시간 합계에서는 제외합니다.
- 선택한 회차의 **오늘 청취 합계**와 강좌별 오늘 기록 여부를 표시합니다. 과거에 완료했어도 오늘 다시 들었다면 **오늘 미기록 N개 강좌 학습 기록**으로 강좌당 18분을 추가합니다. 이미 오늘 기록이 있는 강좌는 건드리지 않아 기본값 기준 3강좌는 54분으로 합산합니다. 과거의 실제 날짜·시간은 보존하며, 사용자 입력 없이 오늘 학습으로 추측하지 않습니다.
- `src/dates.ts`는 기기 로컬 날짜와 기간 계산, `src/studyTime.ts`는 실제 학습일 기반 시간 집계, `src/ebs.ts`는 중복 방지와 기본 18분 기록을 담당합니다. 온라인 동기화 없이 기존 브라우저 저장소를 사용합니다.

## 완료 토글과 시간 통계

- 완료를 취소하면 해당 회차의 완료·추가 학습 기록은 삭제하지 않고 `completed: false`, `voided: true`로 보관합니다. 취소 기록은 완료율과 HOME·학습 기록 화면의 시간 합계에서 제외됩니다.
- 취소 후 다시 완료하면 기기 로컬 날짜·기본 18분으로 새 기록을 생성합니다. 취소했던 기록의 날짜·시간을 되살리지 않아 과거 날짜 때문에 오늘 합계에서 빠지는 문제를 방지합니다. 취소된 원본은 보존하고 기존 날짜·시간 미입력 이력을 소급 변경하지 않습니다.
- 취소한 기록은 내부에 보존하며 기본 학습 기록·청취 이력 목록에서는 숨깁니다. 기록이 있었지만 모두 취소된 기간의 시간 합계는 0분으로 표시합니다.

## 관세사 · 무역영어 강의 목록

- 사용자 제공 60강의 번호·제목·교재 페이지를 원래 순서대로 보존합니다. 강의 길이는 **괄호 안 숫자만** 사용하며, 전체 3,358분은 자료 분량입니다.
- 사용자 요청에 따라 **60강 전부 미수강**으로 시작합니다. 붙여넣은 수강일·재생시간·최근 재생 표시는 학습 이력으로 가져오지 않습니다. 실제 수강 완료·시간·날짜 기록을 임의로 생성하지 않습니다.
- 강의 화면 최상단 **빠른 수강 체크**에서 회독·강의를 고르고 **수강 완료하기**를 한 번 누르면 기기 로컬 날짜로 완료 기록을 저장합니다. 다시 누르면 해당 회독·강의의 완료 기록을 삭제하며, 다른 회독·강의나 진행 중인 기록은 유지합니다. 완료 후 강의는 자동 이동하지 않습니다.
- 수강 완료 시 **강의 길이가 기본 학습시간**으로 저장되어 HOME에 합산됩니다. 빠른 체크와 강의 목록의 새 기록 모두 강의 시간이 미리 입력되며, 완료 전 또는 날짜·시간 수정에서 바꿀 수 있습니다. 입력값을 지우고 새 완료 기록을 저장해도 해당 강의 길이를 기본으로 사용합니다. 기존에 저장한 기록·시간은 소급 변경하지 않습니다.
- 관세사 화면 및 보관함에서 **무역영어 이론·협약**으로 접근합니다. 20강씩 페이지를 나누고 번호·제목으로 검색할 수 있습니다. 실제 수강 후 기존 학습 기록 입력에서 날짜·시간·완료 여부를 따로 저장합니다. 등록만으로는 시간이 합산되지 않으며, 수강 완료 기록을 저장할 때 해당 강의 시간을 기본값으로 사용합니다.
- `Material.kind: "lectures"`와 선택적인 `lectures` 메타데이터로 관리합니다. 기존 브라우저에는 자료 ID가 없을 때만 추가하며, 기존 자료 설정·학습 기록·목표·과업 및 이후 수정은 유지합니다. 원본 데이터는 `src/catalogs/customsTradeEnglish.ts`에 분리했습니다.

## 영어 단어장 이어서 학습

일반 영어 단어장(303 Days)과 구동사·표현 단어장(35 Days)에 동일하게 적용됩니다. Grammar in Use·다른 자료의 기존 구조는 유지합니다.

- 최상단 **이어서 학습하기**에서 현재 회독의 다음 학습 Day로 이동합니다. 전체 Day 목록을 나열하지 않습니다.
- Day 번호 직접 입력은 유효한 범위 안에서 즉시 이동하며 이전/다음 Day 버튼도 제공합니다. 탐색한 Day는 실제 학습 진도와 별도로 저장됩니다. 과거 Day를 열어도 이어서 학습할 위치는 바뀌지 않습니다.
- 회독 선택·현재 Day·누적 복습 횟수·**복습 기록하기**·Day 이동을 하나의 패널에서 제공합니다. 전체 Day 목록은 기본 화면에 펼치지 않으며, 해당 Day의 상세 이력과 회독 현황·자료 설정은 접힌 보조 영역에서 확인합니다.
- **새 Day 학습**은 마지막 번호 다음 Day를 추가하면서 기기 로컬 날짜로 **신규 학습**을 함께 저장합니다. 실제 학습시간과 메모는 선택 입력이며, 입력한 시간은 HOME 통계에 포함합니다. 시간 미입력은 임의로 채우지 않습니다. 단어·예문 원문은 기존 Excel에서 관리합니다.
- 신규 학습은 `initialLearning: true`, `activity: "study"`로 저장합니다. Day별 **신규 학습 횟수**와 **복습 횟수**를 분리하며, 신규 학습 자체가 복습 회독을 완료시키지 않습니다. 기존 기록은 신규 학습으로 추측하거나 다시 분류하지 않습니다. Excel 서식 정리 등 자료 정비는 기존 과업·정비 시간과 구분합니다.
- 이미 완료한 회독은 Day 추가 시 그때의 Day 수를 `DayRoundState.totalDays`에 보존합니다. 진행 중인 회독과 새 회독은 늘어난 전체 Day 수를 사용합니다. 완료한 회독 범위 밖의 Day를 복습하려면 새 회독을 시작합니다.
- 신규 학습 기록 취소는 기록·시간만 삭제하며 추가한 Day와 다른 복습 기록은 보존합니다. 상세 이력의 **이 Day 신규 학습 기록**으로 기존 Day에도 다시 기록할 수 있습니다. 신규 학습의 날짜·시간·메모는 기록 수정에서 변경할 수 있습니다.
- **복습 기록하기**는 기기 로컬 날짜로 새 복습 이력을 저장합니다. 기록을 추가·수정·취소해도 선택한 Day는 이동하지 않습니다. 같은 Day를 여러 번 기록할 수 있으며 누적 횟수에 반영됩니다. 학습시간은 임의로 추정하지 않고 미입력으로 두며 기록 수정에서 입력할 수 있습니다. 실제 단어·예문은 기존 Excel 자료를 참고하세요.
- 회독별 `nextDay`(다음 미완료 Day), `lastOpenedDay`(선택한 Day), 최근 복습 ID를 `DashboardData.dayBooks`에 별도로 저장합니다. `activeRound`로 현재 회독을 유지하며 재접속하면 진행 중이던 회독의 마지막 선택 Day를 표시합니다. 다른 회독으로 전환해도 각 회독의 선택 위치는 유지됩니다.
- 기존 저장 데이터에 이 정보가 없으면 기록을 보존하면서 초기화합니다. **가장 높은 완료 Day + 1을 사용하지 않습니다.** 활성 완료 기록 사이의 첫 미완료 Day를 계산하므로 Day 1·3·100이 완료되었어도 다음 미완료 Day는 2입니다. 회독 현황에서 해당 Day를 직접 열 수 있습니다. 이전의 `01` 같은 Day 번호도 같은 Day로 읽습니다.
- **최근 기록 취소**와 상세 이력의 **기록 취소**는 해당 복습 기록을 실제로 삭제합니다. 회독 이력·누적 횟수·시간 집계와 다음 미완료 Day도 남아 있는 기록을 기준으로 갱신합니다. 기존에 취소 상태로 보관되던 단어장 기록도 불러올 때 정리합니다. EBS 취소는 내부 보관 후 집계에서 제외하며, 다시 완료할 때는 새 청취 기록을 생성합니다.
- 회독 선택·번호 직접 입력·새 회독 시작을 지원합니다. 목표 회독 횟수와 무관하게 추가할 수 있으며 마지막 Day를 기록해도 새 회독을 자동 생성하지 않습니다. 기존 회독의 진도와 선택 위치는 각각 보존됩니다.
- 기존 학습 기록 화면에서 날짜·시간·Day·회독을 수정하는 경우에도 같은 저장 로직으로 다음 미완료 Day를 갱신하고 선택 위치는 유지합니다. 자료 상태를 변경해도 학습 기록은 보존합니다. 자료 전체량 변경 시 위치를 유효 범위로 조정합니다.

주요 파일: `src/dayLearning.ts`(진도·탐색·회독 및 취소 로직), `src/DayBook.tsx`(단어장 UI), `tests/dayLearning.test.mjs`(위치 분리·순서가 뒤섞인 이력·취소·회독·저장 회귀 검사). 저장은 동일 브라우저·동일 사이트의 로컬 저장소이며 온라인 동기화는 제공하지 않습니다.
